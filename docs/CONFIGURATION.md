# Pageforge 設定

共用預設值在根目錄 `pageforge.config.json`。個人設定請將
`pageforge.config.local.example.json` 複製為 `pageforge.config.local.json`；
只需要寫要覆寫的欄位。本機設定檔不會提交到 Git。

優先序：環境變數 > 本機覆寫檔 > 共用設定檔。
支援環境變數 `PAGEFORGE_PORT`、`PAGEFORGE_DEV_PORT`、
`PAGEFORGE_LIBRARY_ROOT`、`PAGEFORGE_WEB_ROOT`。
相對路徑均以專案根目錄為準，與啟動時所在目錄無關。

| 設定    | 用途                                                                             |
| ------- | -------------------------------------------------------------------------------- |
| server  | 對外的本機連接埠、Next 開發連接埠；必須不同                                      |
| paths   | 書架根目錄、靜態網站輸出目錄                                                     |
| limits  | 匯入與文字快照容量、筆記快照容量、歷史匯入版本數、ZIP 解壓限制、試算表與筆記上限 |
| reading | 預設字級、可選字級、進度保存間隔、PDF 頁碼上限                                   |
| diff    | 比較文字的總字元上限、計算逾時、最大編輯距離                                     |

容量單位 MiB = 1,048,576 bytes；字元長度依 JavaScript 字串長度計算。
`limits.imageMiB` 控制每張本機圖片大小，預設 8 MiB。
`limits.workingCopyCount` 控制每份文件可保留的草稿數量，預設 30。
`reading.draftDebounceMs` 控制輸入後自動暫存間隔，預設 500 ms；切換前會立即等待暫存。
修改後重啟服務，重新整理網頁即可。服務會將閱讀與容量設定提供給前端，
不必為本機覆寫重新建置；純靜態瀏覽器模式使用建置時的共用預設值。
已有的字級若不在新選項中，會使用新的預設值，文件與 VAX 歷史不受影響。
降低限制會影響後續匯入或保存，不會改寫既有版本。

執行 `pnpm config:check` 檢查實際生效的設定。
未知欄位、無效連接埠、字級、容量組合會在啟動前報錯。
本機服務固定綁定 `127.0.0.1`。資料結構、資料庫識別與 VAX 驗證規則是固定協定。
桌面開發模式也使用同一份連接埠設定；桌面封裝目前仍使用靜態網站模式。
