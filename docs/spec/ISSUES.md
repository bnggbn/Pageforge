# 待辦與已知限制

## 已接上的 Web 能力

- 五種格式匯入、重複檢查、固定 library 資料夾保存與書架；保留 IndexedDB 靜態模式。
- 固定 `/reader/?id=...` 靜態路由，閱讀、字級與位置恢復。
- Markdown／TXT 編輯、引用筆記、VAX 版本驗證、文字／筆記 diff、還原成新版本。
- 原始檔／文字／版本紀錄匯出、確認刪除、多分頁衝突阻擋。
- `pnpm test:web` 的正式建置與瀏覽器完整流程驗證。

## 格式限制

- PDF 使用瀏覽器內建閱讀器，頁碼書籤手動保存；未提供畫線、原位批註或 PDF 文字編輯。
- EPUB 是章節文字閱讀，不保留排版／圖片，不支援 DRM。
- XLSX 不保留 Excel 樣式，不重算公式，日期可能顯示原始序號；不支援 XLS、巨集或儲存格編輯。
- 筆記引用在文字修改後尚不自動重定位；筆記目前可新增／移除，修改需移除後重建。
