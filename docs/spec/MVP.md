# Web 功能與驗收

目前範圍已由使用者擴充為多格式閱讀、筆記、文字編輯與 VAX 版本管理。

## 流程

1. 選取或拖放一個 .md／.txt／.pdf／.epub／.xlsx 文件。
2. 驗證來源與大小，建立 VAX 初始版本，原子保存到本機書架。
3. 開啟閱讀頁；依格式顯示文字、章節、工作表或 PDF 閱讀器。
4. 保存閱讀位置、調整字級、建立筆記。
5. Markdown／TXT 可直接編輯，每次保存新增版本。
6. 比較文字／筆記差異，將舊快照還原成新版本。
7. 下載來源、匯出文字／版本紀錄，或確認刪除。

## 規則

- 文字：UTF-8，最多 5 MiB，拒絕空白與含 NUL 的內容。
- PDF／EPUB／XLSX：最多 20 MiB；ZIP 解壓最多 40 MiB／2,000 項，單項最多 15 MiB。
- XLSX：最多 10,000 列／200 欄／100,000 儲存格。
- 相同原始位元組 SHA-256 與格式視為重複，不新增文件或版本。
- 不執行文件內的 HTML／腳本，不載入文件引用的遠端圖片；Markdown 外部連結只允許 HTTP(S)／mailto 並另開。
- EPUB／XLSX 首版提供閱讀與筆記；原始二進位檔保持不變。
- 編輯與筆記各自留下 VAX 事件，還原不抹除歷史。
- 容量不足與保存錯誤不顯示成功；並行 head 衝突拒絕覆寫。
- 清除網站資料會移除本機內容；不同 origin 的書架互不共用。

## 驗收

`npm run test:web` 會正式建置並驗證：

- 中文 Markdown／TXT、EPUB 章節、XLSX 工作表、PDF 本機 blob。
- 重整保存、閱讀位置與字級恢復、章節選擇恢復。
- 筆記、文字編輯、文字／筆記 diff、還原與來源重複匯入。
- 多分頁修改衝突，UTF-8／PDF 格式錯誤，模擬儲存容量不足，刪除後文件／進度消失。
- 多個螢幕寬度無橫向溢出、版本內容修改後的完整性驗證失敗。
- 文件內容不觸發遠端請求，無瀏覽器執行錯誤。

測試使用自製文件與獨立瀏覽器，不操作使用者書架。瀏覽器 PDF 的實際渲染能力仍需在目標瀏覽器人工確認。
