# Pageforge：你的固定閱讀空間

這份指南是實際存放在 `library/collection/` 的 Markdown 文件。它可以閱讀、做筆記、修改文字，也能比較每次修改留下的版本。

## 一份文件，三種使用方式

### 閱讀

先把值得停留的文字放到書架。Markdown 與純文字支援字級調整及閱讀位置恢復；EPUB 按章節閱讀，XLSX 按工作表查看，PDF 使用瀏覽器閱讀器。

選取一段文字，可以把它帶到頁邊的筆記中。閱讀不需要先登入帳號。

### 做筆記

筆記記錄自己的理解，原文保持不變。可以留下疑問、整理重點，或引用一段想回來再讀的文字。

每次保存或移除筆記，都建立一個版本。你可以在版本紀錄中比較「筆記差異」，也能把舊筆記還原成新版。

### 修改文字

對於自己擁有並允許修改的 Markdown／TXT，切換到「編輯文字」。保存後建立新版本，匯入時的來源檔仍保留。

下面的句子可以用來試一次編輯：

> 今天讀到的文字，值得留下什麼？

修改這句話，再開啟版本紀錄，就能看見新增與刪除的文字。

## 固定資料夾

預設書架放在專案的 `library/`。

- `collection/`：待載入的原始文件。把 `.md`、`.txt`、`.pdf`、`.epub` 或 `.xlsx` 放在這裡，再按「重新載入資料夾」。
- `books/`：已保存的文件，每份文件有自己的 ID 資料夾，包含原始檔、manifest 與 versions。
- `.pageforge/`：閱讀設定與資料夾初始化狀態。
- `.trash/`：從書架移除的文件。

第一次啟動會載入這幾份實際文件。移除全部文件後，不會自行把它們補回來；只有主動重新載入資料夾才會再次匯入。

`collection/` 是匯入來源，編輯不會覆寫這裡的檔案。要取得編輯後的文字，請使用閱讀頁的「匯出目前文字」。

## 用自己的內容取代範例

1. 將自己的文件放入 `library/collection/`，或在畫面選擇「匯入文件」。
2. 重新載入資料夾。
3. 點選書卡即可閱讀。
4. 把不需要的指南從書架移除。

相同來源內容與格式不會重複匯入。若你修改了來源檔再重新載入，目前會建立另一份文件；把外部修改合併成同文件的新版本是後續功能。

## 備份

先關閉 Pageforge，再複製整個 `library/`。原始文件、筆記、版本與進度都在這個資料夾，不必依赖瀏覽器的網站資料。

只複製 `collection/` 不會包含已保存的筆記與版本。

如果此前使用瀏覽器書架，同一個網址下會出現「轉入瀏覽器書架」按鈕。轉入會保留原始的瀏覽器資料，不會自動清除它。

## 目前的格式能力

| 格式 | 閱讀 | 筆記 | 直接修改文字 |
| --- | --- | --- | --- |
| Markdown / TXT | 是 | 是 | 是 |
| PDF | 瀏覽器閱讀器 | 手動標記位置 | 尚未提供 |
| EPUB | 章節文字 | 是 | 尚未提供 |
| XLSX | 儲存格與公式快取值 | 是 | 尚未提供 |

PDF 的頁碼書籤需手動保存。EPUB 尚不保留完整出版社版面與圖片。XLSX 不重算公式，也不保留 Excel 格式。

## 每個版本都有來源

Pageforge 使用 VAX 的 JCS 與 SAI 版本鏈，記錄匯入、文字編輯、筆記及還原。

還原不抹除歷史，而是把舊內容保存成一個新版本。原始檔與每份版本快照可以分別查看、備份和驗證。

本機版本鏈還沒有簽章或外部可信錨點。它能檢查內容是否符合所保存的版本鏈，不代表具有外部公證。
